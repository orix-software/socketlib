

## Description

Open a socket

## Syntax

unsigned char socket (unsigned char domain, unsigned char __type, unsigned char protocol);

## Input

| param      | Description                          |
| ----------- | ------------------------------------ |
| domain | The communication domain (e.g., AF_INET) |
| __type | The type of socket (e.g., SOCK_STREAM) |
| protocol | The protocol to be used (e.g., IPPROTO_TCP) |
